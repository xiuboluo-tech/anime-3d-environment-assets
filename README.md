# Anime 3D Environment Assets

面向动漫风格场景的 3D 建模资产库，用于整理自然环境、幻想元素、材质、贴图和制作参考。

本库采用原创的吉卜力式自然幻想美术方向，但与 Studio Ghibli 无关联，也不收录对其角色、建筑或电影场景的直接复刻。已筛选的约 50 组候选资源、格式、许可和风格处理要求见 [ASSET_CATALOG.md](ASSET_CATALOG.md)。

## 目录结构

- `trees/`：树木、树根、树桩、枝叶和森林组合资产。
- `water/`：水面、水体网格、瀑布、河流、泡沫和相关效果资产。
- `sky/`：天空盒、云层、太阳、月亮、星空和天气背景资产。
- `spirits/`：精灵、光灵、漂浮生物、粒子造型和幻想装饰资产。
- `mountains/`：山体、岩壁、悬崖、远景山脉和地形资产。
- `materials/`：可复用材质、着色器预设和材质说明。
- `textures/`：基础色、法线、粗糙度、遮罩、渐变和特效贴图。
- `references/`：概念图、色板、造型参考和来源记录；请确保拥有保存与使用权限。

每个资产建议使用独立子目录，并包含模型文件、预览图及资产说明。

```text
category/
└── asset-name/
    ├── source/       # Blender 等源文件
    ├── exports/      # glTF、FBX、OBJ 等导出文件
    ├── textures/     # 此资产专用贴图
    ├── preview/      # 预览图或转台图
    └── README.md     # 作者、版本、比例、面数、许可和使用说明
```

## 文件命名建议

- 使用小写英文与连字符，例如 `cherry-tree-small`。
- 贴图可使用 `_basecolor`、`_normal`、`_roughness`、`_metallic`、`_emission` 等后缀。
- 在资产说明中记录尺寸单位、坐标轴、适用软件版本和导出设置。

## 大文件

3D 源文件和高分辨率贴图可能超过 GitHub 的普通文件限制。正式加入大型二进制资产前，建议配置 Git LFS，并避免提交缓存、临时渲染和自动备份文件。
